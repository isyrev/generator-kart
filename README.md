# Извлечение полей УЭЦН

Статический сайт для извлечения номеров узлов и справочных полей из эксплуатационных паспортов УЭЦН (`.docx`).

Работает локально и на **GitHub Pages** (без бэкенда).

## Структура

```
uecn-extractor/
├── index.html
├── css/style.css
├── js/
│   ├── parser.js      # разбор DOCX + извлечение по шаблону
│   └── app.js         # UI, drag-and-drop, выбор шаблона
└── templates/
    ├── index.json     # список доступных шаблонов
    └── uecn-v10.json  # шаблон паспорта v10 (поля 1–72)
```

## Запуск локально

Нужен любой статический сервер (из‑за `fetch` шаблонов):

```bash
cd uecn-extractor
python3 -m http.server 8080
# открыть http://localhost:8080
```

Или VS Code Live Server / `npx serve`.

## GitHub Pages

1. Создайте репозиторий, залейте содержимое `uecn-extractor/` в корень (или в папку `/docs`).
2. Settings → Pages → Source: **Deploy from a branch** → `main` / `/ (root)` или `/docs`.
3. Сайт будет по адресу `https://<user>.github.io/<repo>/`.

> JSZip подключается с CDN (`cdnjs`). Интернет на клиенте нужен только для этой библиотеки (или скачайте её локально в `js/jszip.min.js` и поправьте `index.html`).

## Как пользоваться

1. Выберите шаблон в выпадающем списке.
2. Перетащите `.docx` паспорт в любое место страницы (или нажмите на зону загрузки).
3. Значения появятся колонками; у номеров узлов (поля 1–30) — кнопка **Копировать**.

## Добавление нового шаблона

1. Скопируйте `templates/uecn-v10.json` → `templates/my-template.json`.
2. Отредактируйте:
   - `id`, `name`, `version`
   - `komplektPattern` — regex для «Комплект №»
   - `tableDetect` — маркеры таблицы комплектации
   - `fields` — описание полей (`source`, `part`, `slot`/`key`, `copyable`)
   - `layout` — порядок вывода на экран
3. Добавьте запись в `templates/index.json`:

```json
{
  "id": "my-template",
  "file": "templates/my-template.json",
  "name": "Мой шаблон"
}
```

4. Закоммитьте и запушьте — на GitHub Pages подхватится автоматически.

### Источники полей (`source`)

| source   | Описание |
|----------|----------|
| `komplekt` | Номер комплекта из абзаца |
| `ecn`      | Секции ЭЦН 1Я…7Я (`slot` 0–6, `part`: num/marka/priz) |
| `mlg`      | Модульная ловильная головка |
| `ed`       | Электродвигатель |
| `sensor`   | Погружной датчик |
| `ppo`      | ППО |
| `gs` / `gz` / `ms` | Г/С, гидрозащита, модуль смещения |
| `ok`       | Обратные клапаны + штуцеры (`slot` 0–1) |
| `filter`   | Сепаратор / разобщитель |
| `prot`     | Протектолайзеры по ключу (`Г/З`, `1-я`, `МЛГ`…) |

Логика разбора строк таблицы живёт в `js/parser.js`. Для принципиально другого документа может понадобиться доработать парсер (новый `source`) — шаблон только описывает, **какие** поля и **как** их показывать.

## Дальнейшее развитие

Идеи без ломки текущей схемы:

- экспорт JSON / CSV одной кнопкой;
- несколько комплектаций на странице (сравнение);
- подсветка отличий от предыдущего файла;
- офлайн-режим (локальный JSZip);
- отдельные шаблоны под другие формы (не только УЭЦН v10).

## Совместимость

Проверено на паспортах версии 10 (Ойлпамп Сервис / РН-Юганскнефтегаз): поля 1–30 (номера) и 31–72 (марки/признаки), протектолайзеры в трёх колонках, ППО, МЛГ, ОК/ШУ.
