# Извлечение полей УЭЦН

Статический сайт для GitHub Pages. Перетащите `.docx` паспорт — получите таблицу полей.

## Режимы отображения

| Режим | Колонки | Копирование |
|-------|---------|-------------|
| **Для ЭПОС** | № узла · Марка · Приз · Ø вала · № Муфты | — |
| **Для ММ** | № узла · Марка | кнопка «Копировать» — номера узлов без пустых |
| **Для ЦДС** | № узла · Марка · № Муфты | кнопка «Копировать муфты» — [79]–[89] без пустых |

## Запуск

```bash
cd uecn-extractor
python3 -m http.server 8080
```

Или залить папку на GitHub Pages.

## Шаблон (`templates/uecn-v10.json`)

Понятная структура для добавления полей:

```json
"fields": {
  "1": { "source": "ecn", "slot": 0, "part": "num" },
  "79": { "source": "ecn", "slot": 0, "part": "mufta" }
}
```

**sources:** `komplekt`, `ecn`, `mlg`, `ed`, `sensor`, `ppo`, `gs`, `gz`, `ms`, `ok`, `ks`, `filter`, `prot`

**parts:** `num`, `marka`, `type`, `priz`, `mufta`, `diam`, `shuNum`, …

Режимы (`modes`) описывают только **отображение** — строки `ids` и заголовки. Логика разбора — в `js/parser.js`.
